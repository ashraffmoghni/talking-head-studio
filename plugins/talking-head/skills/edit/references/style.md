# Visual direction

These are starting values for a calm, minimal expert video. A specific user brief takes precedence. Scale pixel values with the output resolution and check actual footage.

## Colour and typography

| Role | Default |
| --- | --- |
| Emphasis | Navy `#163A5F` |
| Main text | Ink `#202A35` |
| Graphic surface | Warm white `#F7F8FA` |
| Supporting text | Slate `#526171` |
| Fine dividers | Pale blue-grey `#D7E1EB` |
| Typeface | Bundled Quicksand variable font |
| Captions at 1080 × 1920 | 60 px, weight 600, line-height 1.3 |
| Caption emphasis | 70 px, weight 700; allow 15–20% more room |
| Graphic headline | 76 px, weight 700 |
| Graphic labels | 44–50 px, weight 600 |
| Large number or standalone keyword | 96–116 px, weight 700 |

Use sentence case. Avoid thin weights, tight tracking and long all-caps lines. Numbers and labels must survive a phone-size preview. Never shrink a dense paragraph to fit a graphic; split the thought instead.

Navy directly on a dark shirt is unreadable. Over footage use a small, opaque warm-white keyword plate with navy text, or place the whole caption on a light panel. White body captions may use a subtle dark outline/shadow over suitable footage. Check contrast against the actual background throughout the shot. Colour and increased weight/size work together, so emphasis does not depend only on colour.

## Layout

Use three reusable modes:

1. **Speaker + captions:** the normal state. The person remains the focus.
2. **Speaker + upper explanation:** a light panel above the speaker for a comparison, diagram or short process. Reframe only if there is enough source image to do so cleanly.
3. **Takeaway:** one concise thought and a user-approved CTA near the end, with the speaker still visible where practical.

For portrait delivery, start with key content inside 108–972 px horizontally and 192–1728 px vertically. Also account for the target app's controls: reserve extra right/bottom space after checking the intended platform. Place captions in a stable lower-middle area away from face, hands and graphics, often about 600 px above the bottom. Do not hard-code that position across every shot.

Keep graphic panels compact and mostly opaque. Use 24–32 px corner radii, 32–48 px padding and, if needed, a very soft shadow. A medical label gets at least 44 px at 1080-wide output. Use fewer labels if the graphic becomes busy.

## Motion and attention

- Entrances: usually 0.35–0.5 s, with 12–20 px movement or a simple reveal.
- Exits: usually 0.2–0.3 s. Let the viewer finish reading first.
- Staged graphic items: around 0.15–0.25 s apart, aligned with the explanation.
- Hold a short callout for 2–4 s as a starting point; more complex graphics need longer.
- Major graphic density: start with one per 8–12 s, then adjust to meaning and reading time.
- Optional punch-in: about 1.00 to 1.04–1.06 at a useful thought boundary, respecting source resolution. Avoid continuous zooming.
- A word can settle from about 0.96 to 1.00; avoid bouncing, pulsing or repeatedly enlarging every spoken word.

Keep the settled text still. One major motion at a time. Calm does not mean frozen: a question resolves, a comparison appears, or a process advances as the speaker explains it. Use those events to earn attention.

## Reference observations

Sampled frames of the Dr. Akhyar hydrogel edit showed a full-height speaker, occasional light upper panels, short captions, yellow emphasis, knee illustrations and a staged examination process. Preserve that speaker/graphic relationship; use navy consistently and make small labels more legible.

Sampled frames of the knee-pain clinic edit showed compact navy panels with line diagrams above the speaker. Keep the economy of that layout, but use a light surface when navy text is required. Do not interpret a schematic as clinical proof.

These observations are drawn from sampled frames, not a complete audio or motion audit. No patient data, source media or screenshots are included in the toolkit.
